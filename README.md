 Unemployment Analysis in India (Python)

 Objective
Analyze unemployment rate data in India using pandas, with a focus on the
impact of Covid-19 and seasonal trends.

 Dataset
 `Unemployment_in_India.csv` (May 2019 - Jun 2020, Rural/Urban)
 `Unemployment_Rate_upto_11_2020.csv` (Jan - Oct 2020, state and zone-wise)

 Steps
1. Data loading
2. Data cleaning
3. Exploratory data analysis
4. Visualization
5. Covid-19 impact analysis
6. Seasonal trends
7. Insights and policy recommendations

 Key Findings
 Unemployment rose from ~9% to over 22% in April-May 2020 due to lockdown.
 Employed people dropped from ~15.6M to ~10.6M in April 2020.
 Rural and urban unemployment both nearly doubled; urban stayed higher.
 Recovery began from June 2020.

 Tools
Python, pandas, numpy, matplotlib, seaborn

 How to run
Place the CSV files in the same folder as the notebook and run all cells.
